# Tag Rugby EPS

Progressive Web App (100 % hors ligne) pour arbitrer, observer et gérer un tournoi de Tag Rugby au collège, avec cartes joueurs à collectionner.

- `index.html`, `style.css`, `app.js`, `manifest.json` : l'application
- `sw.js` : service worker (mise en cache pour l'usage hors ligne)
- `terrain.png` : image du terrain

Données stockées uniquement dans le `localStorage` de l'appareil (aucune requête serveur avec les données des élèves).
