    💾 Sauvegarde

    Sauvegarde du tournoi dans un fichier sur cet appareil (pour changer de tablette ou archiver le cycle).

    🔒 Données personnelles (RGPD)

    • Toutes les données (prénoms, genres, statistiques) sont stockées uniquement sur cet appareil (localStorage du navigateur).
    • L'application n'effectue aucune requête serveur avec les données des élèves : aucun compte, aucun cloud, aucun traceur, aucune police ou bibliothèque externe.
    • Les fichiers exportés (CSV, PNG, JSON) sont créés localement ; leur conservation relève de l'enseignant.
    • Le mode « Dossards » permet d'utiliser l'application sans aucun prénom.
    • Le bouton « Effacer toutes les données » supprime définitivement le tournoi de l'appareil.
